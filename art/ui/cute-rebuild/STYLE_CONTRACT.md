# Cute UI rebuild — 30 October 2026

User rejected the prior flat symbolic art and approved the cuter illustrated proof in style-correction-v002-cute. This contract supersedes the prior visual direction, not game rules or dimensions.

Scope explicitly confirmed by the user: all UI from the beginning, including 51 v001 pieces and 313 round-two pieces. No source code in apps/*/src or packages is owned by this art task.

## Visual rules

- Short, round, friendly silhouettes; purposeful large pixel clusters, not generic geometric medallions.
- Readable material planes: glass rim/liquid, metal bevel, cloth folds, wood and stone facets. Upper-left light, indigo/lavender shadows, cream highlights.
- Warm honey gold, coral/red, mint/teal, lavender and clear blue. Keep saturated focal points and restrained backgrounds so UI text remains readable.
- Preserve native canvas dimensions and origins. Generated large art is a master only: fixed framing, native-grid adaptation, binary alpha, shared palette and visual inspection are separate steps.
- Frame0 remains readable. Element VFX grow, open and dissipate; status icons move subtly; target and ready indicators loop on stable anchors.
- Existing semantic ids remain stable. Rebuilds use v002 files; index entries for superseded assets are replaced, old v001 files remain recoverable.
- No portrait/monster/world art expansion beyond the existing UI list. Title illustration is a real illustrated asset, not a substituted procedural drawing.

## Accepted reference and first native adaptation

Masters in masters/ are the approved cute potion, short fire sword and6-frame fire impact. Native-basis proof tests potion32px, skill24px and fire32px. It preserves material cues and the effect lifecycle at target size; automated dimensions alone are not aesthetic approval.

## Delivery gate

Every required asset must have source provenance, native PNG, metadata and review evidence. Do not label unbuilt or unreviewed assets completed. Final proof includes native/zoom views, live loops, coverage and alpha/palette checks, npm run check, updated handoff/status documentation and a separate branch.
