# GUI_SCREENS.md: รายการหน้าจอสำหรับร่างโครง GUI

เอกสารนี้รวบรวมทุกหน้าจอที่ระบบมีอยู่แล้วตอนนี้ (25 ต.ค. 2026, PR #2) สำหรับนัทใช้ร่างโครง GUI สำหรับแต่ละหน้าบอกว่า:

- ต้องแสดงอะไร
- ผู้เล่นกดอะไรได้
- มีเงื่อนไขอะไร (เช่น ต้องอยู่ในเมือง หรือห้ามอยู่ในไฟต์)
- ใช้ API ไหน

ภาพตอนนี้ทั้งหมดยังเป็น placeholder:

- หน้าต่างต่าง ๆ เป็น HTML overlay (`character-ui.ts`, `market-ui.ts`, `login-ui.ts`)
- แผนที่และฉากต่อสู้วาดด้วย Phaser แบบสี่เหลี่ยม

GUI ใหม่เปลี่ยนหน้าตาได้ทั้งหมด แต่มีกติกาที่ต้องคงไว้:

- client ส่งแค่ "สิ่งที่อยากทำ" (intent) ส่วนผลลัพธ์ server เป็นผู้ตัดสิน
- ปุ่มที่ใช้เงิน ใช้ของ หรือย้ายคู่ใจ ต้องส่ง `operationId` เดิมเมื่อกดซ้ำหลังเน็ตหลุด
- คำขอที่ต้องยืนยันยอด ต้องส่งราคาที่ผู้เล่นเห็นไปด้วยเป็น `expected*` ถ้า server ตอบ `COST_CHANGED` / `CHANGED` ให้โหลดหน้าใหม่แล้วให้ผู้เล่นยืนยันอีกครั้ง

ภาพร่างโครง GUI 11 หน้า (25 ต.ค.) อยู่ที่ https://claude.ai/artifact/GtYqso83Sxj7Q6rBrnSYr4 และรายการชิ้นส่วน UI ให้ Codex อยู่ใน `docs/ART_HANDOFF.md` หัวข้อ 11

ขนาดฉาก, ช่องในสนาม และกรอบ sprite ดูได้ที่ `docs/ART_HANDOFF.md` หัวข้อ 1–3 ส่วนสรุปสั้นอยู่ในหัวข้อ 0 ข้างล่าง

## 1. เข้าสู่ระบบ

- แสดง: ช่อง ID, ช่องรหัสผ่าน, ปุ่ม "เข้าสู่ระบบ" และ "สร้าง ID ใหม่"
- ปุ่ม Google และ Facebook แสดงเฉพาะเมื่อ server ตั้งค่าไว้ (`GET /auth/config` บอกว่ามีปุ่มไหนบ้าง)
- ข้อผิดพลาดที่ต้องแสดงให้ผู้เล่นเห็น:
  - ID ซ้ำ
  - รหัสผิด
  - ล็อก 15 นาทีหลังรหัสผิด 10 ครั้ง (`LOCKED`)
  - สมัครเกิน 5 ครั้งต่อชั่วโมง (`RATE_LIMITED`)
- API: `POST /auth/register`, `POST /auth/login`, `POST /auth/google`, `POST /auth/facebook`
- ยังไม่มี: ลืมรหัสผ่าน (ต้องมีอีเมลก่อน)

## 2. เลือกตัวละคร

- แสดง: 10 ช่อง (O10) แต่ละช่องเป็นชื่อ + เลเวล หรือ "+ สร้างตัวละครใหม่" และแสดงว่าช่องไหนเล่นล่าสุด
- ปุ่ม:
  - เลือกช่อง: `POST /account/select`
  - ลบตัวละคร: `POST /account/delete` ต้องพิมพ์ชื่อยืนยัน และใส่รหัสผ่านถ้าใช้ ID ในระบบ
  - เปลี่ยนรหัสผ่าน: `POST /auth/password` มีเฉพาะบัญชี ID ในระบบ
  - ออกจากระบบ: `POST /auth/logout`
- คำเตือนก่อนลบ: ของทั้งหมดหาย เหลือเฉพาะที่อยู่ในคลังรวม และลบแล้วกู้คืนไม่ได้
- ข้อมูล: `GET /account`

## 3. สร้างตัวละคร

- เลือก:
  - ชื่อ
  - อาชีพ 9 แบบ: ผู้พิทักษ์ นักรบ นักล่า จอมเวท ผู้เยียวยา ผู้ประสานคู่ใจ นักลอบเร้น นักปรุงแปรธาตุ นักขับขาน
  - เผ่า 8 แบบ: มนุษย์ ชาวพฤกษ์ ชาวศิลา เผ่าสัตว์ ชาวอาคม ชาวสมุทร ชาวเวหา ชาวสนธยา
  - ธาตุ
- ควรแสดงคำอธิบายสั้นและ passive ของอาชีพและเผ่าที่เลือก
- API: `POST /character` (`operationId`, `name`, `classId`, `raceId`, `element`)

## 4. แผนที่ (ฉากหลัก)

**บนจอตลอดเวลา (HUD)**

- ชื่อแผนที่ · channel · จำนวนคนในแต่ละ channel · ผู้เล่นที่เห็น
- ฉายา + ชื่อ + เลเวล + EXP + แต้มสเตตัสว่าง + HP/MP
- สถานะ "ล่าอัตโนมัติ: เปิด"
- ข้อความแจ้งเตือนสั้น เช่น Bond ขึ้น, เลเวลอัป, ของเข้ากล่องจดหมาย

**ในโลก**

- ผู้เล่นคนอื่นแสดงชื่อ ฉายา และแฟชั่นที่ใส่
- ฝูงมอนเดินไปมา (ฝูง Elite ขอบเหลือง)
- บอสเจ้าถิ่น
- NPC 14 คนในเมือง
- ประตูไปแผนที่อื่น

**การควบคุม**

- เดิน 8 ทิศ ใช้ลูกศร/WASD หรือแตะพื้น
- แตะฝูง = เข้าไฟต์ (ไฟต์ส่วนตัว ไม่มีแย่งมอน)
- แตะบอส = ท้า ต้องยืนใกล้ ถ้ามีเพื่อนปาร์ตี้ยืนใกล้ ทุกคนเข้าไฟต์ด้วยกัน
- แตะ NPC = เปิดบริการของคนนั้น
- ปุ่ม 1/2 = เปลี่ยน channel ถ้า channel เต็ม ระบบย้ายให้อัตโนมัติ

**API**

- WebSocket `GET /world/:mapId/:channel` สำหรับเดินและเห็นคนอื่น
- `GET /world/where` และ `GET /world/channels/:mapId`

## 5. ฉากต่อสู้

**สนาม**

- ไฟต์ปกติ: ฝ่ายเรา 2 แถว × 3 ช่อง
- ไฟต์บอสปาร์ตี้: ฝ่ายเรา 2 แถว × 5 ช่อง (สูงสุด 5 คน × 1 คู่ใจ)
- ศัตรู 2 แถว × 5 ช่อง สูงสุด 10 ตัว
- ทุกตัวต้องแตะเพื่อเลือกเป้าได้ (สูงสุด 20 ตัวบนจอ)

**รอบตัวแต่ละตัว**

- ชื่อ + เลเวล
- แถบ HP
- ไอคอนสถานะ (24 แบบ)
- ป้าย Elite/บอส
- ชิ้นส่วนบอสที่ทำลายได้
- โล่
- เกจจุติเทพ

**แถวคำสั่ง (ปุ่มละ 48 px)**

- โจมตี
- สกิล: เลือกสกิล แสดง MP และคูลดาวน์เป็นตา
- ป้องกัน
- ยา: รวมยาหมู่และไอเทมปาใส่ศัตรู
- ชุบ
- จับ: ไม่จับอัตโนมัติ
- หนี
- จุติ: เมื่อเกจเต็ม
- Auto: เปิด/ปิด

**ข้อมูลอื่นบนจอ**

- บอกว่าตาของใคร
- ข้อความเหตุการณ์ (log)
- ตัวเลขดาเมจ/ฮีลเด้ง
- นับถอยหลัง 2 นาทีก่อนไฟต์ที่ไม่มีใครสั่งถูกปิดเป็นแพ้ (P36)

**ไฟต์พิเศษ (ข้อมูลเพิ่มบนจอ)**

- หอคอย: ชื่อชั้น ลูกเล่นของชั้น และกำลังเสริมที่เหลือ
- บอส: phase, คำเตือนท่าใหญ่, ชิ้นส่วนที่ผนึกสกิล
- บอสปาร์ตี้: สั่งได้เฉพาะตัวของตัวเอง ถ้าตาค้าง 30 วิ Auto เล่นแทน
- บททดสอบ (อาชีพ/จุติเทพ/Rebirth): เป้าหมายที่ต้องทำให้ครบ
- ลานทดสอบ: ไม่ได้และไม่เสียอะไร

**จบไฟต์**

- สรุปผล: EXP ของตัวละคร/คู่ใจ, เลเวลอัป, ของที่ได้, คู่ใจที่จับได้, Bond
- ปุ่ม "เดินต่อ"

**API**

- `GET /battles/:id`, `GET /battles/:id/events?since=N`
- `POST /battles/:id/commands`, `POST /battles/:id/auto`
- `POST /battles/:id/session` (ต่อใหม่หลังเน็ตหลุด)

## 6. หน้าต่างซ้อน (เปิดจากแผนที่)

ตัวย่อในคอลัมน์ "เงื่อนไข": **เมือง** = ต้องอยู่ในเมือง; **นอกไฟต์** = ทำไม่ได้ระหว่างไฟต์; **retry** = ต้องส่ง `operationId` เดิมเมื่อกดซ้ำ
