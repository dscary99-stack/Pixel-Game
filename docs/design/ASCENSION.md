## เงื่อนไขและราคา
- เปิดที่ Lv200 และต้องรับ Class3 แล้ว (บท02); ไม่มีเหรียญ Weekly ไม่ต้องรอวัน ไม่มี Premium
- บททดสอบเผ่า: คุยผู้ใหญ่พิมพ์ (หน้าต่างเปลี่ยนอาชีพ) → ไฟต์ซ้อมแบบลานทดสอบ (ไม่ได้ไม่เสีย HP เต็ม ไม่พกไอเทม พาทีมได้) กับจอมทรราชหอคอยที่แรงขึ้น **1000%**
  - จำลอง: ตัวละคร Lv200 แต้ม Class1 50 + Class2 70 + Class3 70 สเตตัสซื้อตามราคาที่ขึ้น ของร้าน Lv40 คู่ใจ Lv195 ×3 บน Auto ชนะ 48/54 (900% 52/54, 1200% 36/54); Ruin Champion แพ้ทั้ง 3 ต้องเล่นมือ
  - บท02 "ผ่านได้หลายอาชีพ": ทุกอาชีพผ่านได้ด้วยทีม (ไม่บังคับต้องเป็น healer); ต้องทำเป้าหมายประจำเผ่าด้วย (ดูหัวข้อด้านล่าง)
- ชนะแล้วรับในเมือง: **2,000,000 เหรียญ + แกนรอยแยก (`item:rift_core`) ×10** แล้วเลือกวิถี A/B (ยังไม่มีวัสดุ Lv200 จริง จึงใช้ของดรอปผู้คุ้มหอคอย)
- เปลี่ยนวิถีในเมือง **500,000 เหรียญ** (coin sink แบบเปลี่ยนสาย Rebirth)

## ในไฟต์
- Passive เผ่าถูกแทนด้วย passive ของวิถี (ไม่ซ้อนของเดิม)
- เกจจุติเริ่ม 0 ทุกไฟต์; ตี/ฮีล/ติดสถานะ/ได้โล่/ชุบ/ใช้ไอเทมที่มีผลจริง +25 (รอบละไม่เกิน 25); ป้องกัน สลับตำแหน่ง หนี ไม่นับ
- เกจเต็ม 100 → กด "จุติ" ใช้ action ของตานั้น ครั้งเดียวต่อไฟต์ อยู่ 3 ตาของตัวเอง (ตาที่กดไม่นับ); สิ่งที่หยุดสกิลก็หยุดจุติ
- Auto ตั้งได้: ใช้ทันที / เฉพาะเจอ Elite-บอส / HP ต่ำกว่าครึ่ง / ไม่ใช้ (ค่าเริ่ม: ใช้ทันที)
- ผลจุติ: บัฟของวิถีกับตัวเอง/ทั้งทีม (ติดแน่นอน) หรือดีบัฟศัตรูทั้งหมด (ทอยโอกาสตามปกติ) นาน 3 ตา
- จำลองที่ 1200%: มี/ไม่มีจุติชนะใกล้กัน (10–13/18 ต่อวิถี เทียบ 12/18) = เล็กกว่าแกนอาชีพตามบท02 นัทปรับให้แรงขึ้นได้
